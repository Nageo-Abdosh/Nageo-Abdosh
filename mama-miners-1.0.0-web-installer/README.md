
# Mama Miners – Software Package

## Description
Mama Miners is a PHP-based web application with authentication, user dashboard, referrals, and admin panel.

## Requirements
- PHP 8.x
- MySQL / MariaDB
- Apache or Nginx

## Installation
1. Upload files to your web server
2. Import `sql/database.sql` into your database
3. Configure database in `config.php`
4. Visit `/setup.php`

## Admin Panel
`/admin`

## Security
- Change default credentials
- Restrict admin directory
